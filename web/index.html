Impractical Pythons

A pier full of silly little Python machines. Pull a lever for a secret identity, pass a scrambled note to a friend, weigh your words in candy, cast a spell in a magic mirror. Every stall runs real Python right here in your browser.

The ideas were sparked by Impractical Python Projects by Lee Vaughan. If these make you want to build your own odd little programs, that book is a brilliant place to start.

    Inspired by Impractical Python Projects by Lee Vaughan. The stalls, their words and their code are new. All the Python is on GitHub.
