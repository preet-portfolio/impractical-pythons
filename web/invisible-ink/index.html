    How vanishing ink works

    Hiding the fact that there's a message at all is steganography. Here it's as simple as it gets: set the text colour to the paper colour. A printout drops it. A quick look sees blank lines between paragraphs, which every letter has. The secret only goes in those gaps, never between words, because letters in most fonts are different widths and a hidden word would push the visible ones apart.

    The ink is scrambled too, in case someone does look. The Vigenère cipher writes a key word over the message again and again: K I T E K I T E over c r a b s… Each key letter says how far to shift the letter under it (A is 0, B is 1, … K is 10), so "crab" with KITE becomes "mztf". The same letter scrambles differently each time, which kept the cipher unbroken for three hundred years. Numbers and symbols don't shift, so the shop can write them as words first.

    It isn't perfect. Selecting everything shows some blank lines are longer than others; a spellchecker underlines words nobody can see; saving as plain text drops the colour. The buttons on the counter show all three. The Word file is built by Python in your browser, straight from the zip and XML inside every .docx, and a second bit of Python reads any letter back to look for ink. Peek at the Python.
