    How it works

    Classic Pig Latin moves a word's opening consonants to the end and adds ay, so nix becomes ixnay. But it can't be undone reliably: does away come from way or from a? Code-Talk puts a hyphen where the word was cut (ix-nay, apple-ay), so every word carries the instructions to put it back.

    The Python finds words with a regular expression and rebuilds each one with string slicing: word[split:] + "-" + word[:split] + "ay". The whole consonant cluster moves (string becomes ing-stray), qu stays together, and y is a consonant only at the start. Capitals, punctuation, numbers and real hyphens stay where they were.
