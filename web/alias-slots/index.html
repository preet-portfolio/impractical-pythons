    How it works

    Every spin runs real Python in your browser, using Pyodide. Each reel is a tuple of words. A seeded random.Random picks where every reel stops, and a held reel keeps its place. Three reels starting with the same letter pays the jackpot. Two reels ending in the same three letters is a rhyme, and two matching first letters is a pair. The odds come from trying every possible spin with itertools.product.

    The link for each alias is a short base-36 number that packs in the machine and where each reel stopped. Read the Python.
